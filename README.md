# How to sync
 
## When you start working on a machine
 
### First get latest changes before modifying:
 
> git pull
 
 
### After you modify scripts:
 
> git add .
 
> git commit -m "describe change"
 
> git push
 
## After making changes to .gitignore file
 
> git rm -r --cached .
 
> git add .
 
> git commit -m "fix gitignore"
