TABLE: ZFI_CV_BUCKET
Description: Customer/Vendor Ageing Report - Bucket Configuration

Key Structure (4 fields):
┌──────────────┬──────────┬────────────────────────────────┐
│ Field Name   │ Data Type│ Description                    │
├──────────────┼──────────┼────────────────────────────────┤
│ VARIANT      │ CHAR(4)  │ Bucket Variant ID (Primary Key)│
│ SNO          │ INT4     │ Sequence Number (Primary Key)  │
│ FROM_SEL     │ INT3     │ From Value (days/years)        │
│ TO_SEL       │ INT3     │ To Value (days/years)          │
│ DURATION_TYPE│ CHAR(2)  │ D,Y,D+,Y+ (Primary Key)        │
│ FROM_TO      │ CHAR(30) │ Bucket Key (0TO30DAYS, etc)    │
│ FROM_TO_DESC │ CHAR(60) │ Bucket Label (0 to 30 Days)    │
│ CREATED_BY   │ CHAR(12) │ User who created/modified      │
│ CREATED_DATE │ DATS     │ Creation date                  │
└──────────────┴──────────┴────────────────────────────────┘

Duration Types:
- D  = Days range (0-30 days, 31-60 days, etc.)
- Y  = Years range (1-2 years old, 2-3 years old, etc.)
- D+ = Days and older, open-ended (90+ days, etc.)
- Y+ = Years and older, open-ended (2+ years old, etc.)
